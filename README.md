# AI 数据分析工作台

《统计与数据分析基础》（人民邮电出版社）配套实训工具：**上传数据自己跑**。十个课堂实训作为预设集与验收手段。

单文件全内联（`index.html`，零外部依赖），双击即开（file:// 直接运行），所有计算在浏览器本地完成，数据不出浏览器。

## 使用流程

**信息架构（v2 平台壳）**：
- **顶栏**：品牌 Logo + 全局搜索（示例 / 知识 / 图表）+ AI 助手 / 通知 / 帮助 + 用户头像
- **左侧多级导航**：首页 / 工作台 / 知识库（5 子项）/ 实训中心（10 子项，动态生成）/ 数据工作台（4 子项）/ 输出中心（4 子项）
- **主区**：根据左侧菜单路由切换五个 view（home / workspace / knowledge / training / output）
- **底栏**：系统状态 + 版本 v2.2.0 + 技术支持 + 反馈建议

**电脑端（默认）—— 三栏式分析工作台**（位于「工作台」路由下）：左栏选数据源 / 看变量列表，中栏选分析能力并调参数，右栏看结果与解读，右侧可独立滚动。

**手机端 —— 自动降级**：窗口宽度 < 768px 时侧栏折叠为汉堡菜单 + 抽屉，工作台布局降级为三步向导（选数据 → 选分析 → 看结果）。

**首页**：问候语 + 4 个快捷入口（上传数据 / AI 智能分析 / 从模板开始 / 学习知识库）+ 最近项目 4 张卡 + 数据概览 6 项指标（数据源 / 数据集 / 分析能力 / 图表 / 报告 / PPT 文稿）。

结果统一为：指标卡 + 公式卡 + SVG 图表 + 分层结论 + 推荐 Prompt，可一键导出独立 HTML 报告。

### 关于「壳子模式」

后三项能力的 **UI 与逻辑设计已完成、数值算法待接入**。选中它们并运行时，不会给出假的统计结果，而是展示一份设计规格预览：

1. **数据体检** —— 当前数据是否适配（分组数与每组样本量、列联表规模、配对数）
2. **将输出的关键指标** —— F / χ² / U 等统计量与效应量清单
3. **将使用的公式** —— 教材口径的公式清单（平方和分解、期望频数、秩次转换等）
4. **将绘制的图表** —— 箱线图、热力图、秩次分布图等
5. **将给出的分层解读** —— 事实 / 分析 / 警示 / 建议四层
6. **待接入的算法清单** —— 需新增的函数名、职责与参考（如 `fDistP`、`chi2P`、`rankAll`）
7. **设计约定与前提假设** —— 缺失处理、适用条件、LLM 不心算铁律
8. **推荐 Prompt 模板**

规格确认后再逐个填算法，避免填到一半发现参数设计要返工。

## 统计口径

- 样本方差 / 标准差：ddof = 1
- 置信区间：z = 1.96（95%）
- 统计指数：拉氏产量 × 帕氏价格，体系自洽双重校验（K总 = Kq拉 × Kp帕）
- 发展速度：几何平均 ⁿ⁻¹√(yₙ/y₁)
- 异常值：IQR 法，四分位取 Excel 口径
- t 检验：Welch 近似 df（Satterthwaite）、p 值经正则化不完全 Beta 函数、Cohen's d 效应量，与 scipy.stats 一致
- 口径与 Python 侧引擎（`engine/`）完全一致，报告墙预生成结果与工作台内计算可互相印证
