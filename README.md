# AI 数据分析工作台

《统计与数据分析基础》（人民邮电出版社）配套实训工具：**上传数据自己跑**。十个课堂实训作为预设集与验收手段。

单文件全内联（`index.html`，零外部依赖），双击即开（file:// 直接运行），所有计算在浏览器本地完成，数据不出浏览器。

## 使用流程

**当前界面（v0.1）**：固定顶栏 + 单页三栏式工作台。左栏上传 CSV、选择课堂示例并查看变量；中栏选择分析方法和参数；右栏显示指标、公式、图表、结论与可导出的独立报告。

**电脑端**：三栏独立滚动，适合连续调整数据与参数。

**手机端**：窗口宽度 < 768px 时三栏改为纵向堆叠，按“数据 → 分析 → 结果”顺序操作，不再压缩成不可用的窄栏。

结果统一为：指标卡 + 公式卡 + SVG 图表 + 分层结论 + 推荐 Prompt，可一键导出独立 HTML 报告。

## 统计口径

- 样本方差 / 标准差：ddof = 1
- 置信区间：z = 1.96（95%）
- 统计指数：拉氏产量 × 帕氏价格，体系自洽双重校验（K总 = Kq拉 × Kp帕）
- 发展速度：几何平均 ⁿ⁻¹√(yₙ/y₁)
- 异常值：IQR 法，四分位取 Excel 口径
- t 检验：Welch 近似 df（Satterthwaite）、p 值经正则化不完全 Beta 函数、Cohen's d 效应量，与 scipy.stats 一致
- ANOVA：经典单因素模型；两两比较支持 Bonferroni 或 LSD。未把 Bonferroni 近似标为 Tukey HSD。
- 卡方：2×2 表可使用 Yates 连续性校正；拟合优度的理论比例必须与类别数一致。
- 非参数：Mann-Whitney 与 Wilcoxon 使用带并列秩与可选连续性校正的正态近似；当前未提供精确 p 值。
- 口径与 Python 侧引擎（`engine/`）完全一致，报告墙预生成结果与工作台内计算可互相印证
