# AI 数据分析工作台

《统计与数据分析基础》（人民邮电出版社）配套实训工具：**上传数据自己跑**。定位为教学级统计实训工具，十个课堂实训作为预设集与验收手段。

单文件全内联（`index.html`，零外部依赖），双击即开（file:// 直接运行），所有计算在浏览器本地完成，数据不出浏览器。

## 使用流程

**当前界面**：固定顶栏 + 单页三栏式工作台。左栏上传 CSV、选择课堂示例并查看变量；中栏选择分析方法和参数；右栏以「报告式」呈现结果 —— 报告头（方法 + 数据上下文 + 一句结论摘要）→ 核心图表 → 关键指标 → 分层解读，可一键导出独立 HTML 报告。

**电脑端**：三栏独立滚动，适合连续调整数据与参数。

**手机端**：窗口宽度 < 768px 时三栏改为纵向堆叠，按“数据 → 分析 → 结果”顺序操作，不再压缩成不可用的窄栏。

结果统一为「单页报告式」：报告头（方法 + 数据上下文 + 结论摘要）→ 核心图表（方法特定，主角）→ 指标卡 / 公式卡支撑 → 分层解读（事实 / 分析 / 建议），可一键导出独立 HTML 报告。

## 统计口径

- 样本方差 / 标准差：ddof = 1
- 置信区间：z = 1.96（95%）
- 统计指数：拉氏产量 × 帕氏价格，体系自洽双重校验（K总 = Kq拉 × Kp帕）
- 发展速度：几何平均 ⁿ⁻¹√(yₙ/y₁)
- 异常值：IQR 法，四分位取 Excel 口径
- t 检验：Welch 近似 df（Satterthwaite）、p 值经正则化不完全 Beta 函数、Cohen's d 效应量，与 scipy.stats 一致
- ANOVA：经典单因素模型；两两比较支持 Bonferroni 或 LSD。未把 Bonferroni 近似标为 Tukey HSD。
- 卡方：2×2 表可使用 Yates 连续性校正；拟合优度的理论比例必须与类别数一致。
- 非参数：Mann-Whitney 与 Wilcoxon 使用带并列秩与可选连续性校正的正态近似；当前未提供精确 p 值。
- 浏览器端（JS）与 Python 侧引擎（`engine/`）为「双引擎」，共用同一套统计口径；课堂实训的 9 个报告墙任务两侧已对齐，扩能的专业方法（相关矩阵 / 聚类 / 多元回归 / 逻辑回归 / 因子 / 信度 / 正态性）目前仅 JS 侧实现，Python 侧按需补齐

## 双引擎

工作台由两套代码干同一件事，结果必须一致：

- **浏览器 JS 引擎**（`index.html` 内联）：交互工作台。双击即开、数据不出浏览器、现场计算 + SVG 图表 + 报告式结果。
- **Python 引擎**（`engine/`）：批量报告墙 + QA 校验基准。用 pandas / scipy 批量生成 `output/taskNN/` 标准报告、PNG、PPT，并作为「基准真相」复算 JS 结果是否算错（容差 1e-6）。

新增分析方法时按需在两侧同步实现并核对口径。
